# Programming vs Programming Language

## What Is Programming?

Programming is the process of writing instructions step by step to tell a computer what to do and how to perform a task.

### What Is a Programming Language?

A programming language is a language used to communicate with a computer by writing instructions in a format that the computer can understand and execute.

## What Is Python?

Python is a simple, high-level programming language. It is easy to read, write, and understand. It is used for web development, automation, data analysis, artificial intelligence, and machine learning.

## What Is Syntax?

Syntax is the set of rules that tells us how to write instructions correctly in a programming language. If we do not follow the syntax rules, we may get errors.

## Programming and Python

### Explain the Difference Between Programming and Python.

Programming is the process of creating instructions to solve a problem, whereas Python is a programming language used to write those instructions.

### What Remained the Same?

The logic and steps used to solve the problem remained the same in both pseudocode and Python. The input, processing, and output also remained the same.

## What Changed?

The writing style and rules changed when pseudocode was converted into Python. Pseudocode uses simple English-like instructions, whereas Python follows specific syntax rules and keywords to execute the program.
